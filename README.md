# AWS EKS with Terraform — Portfolio Project

Infrastructure-as-code demonstration for provisioning a private-node Amazon EKS cluster with Terraform. The implementation is proposed in a pull request so its design and review history are visible.

> **Portfolio/demo project** — not an assertion of deployment or production use. Running `terraform apply` creates billable AWS infrastructure. No deployment occurs automatically.

See the `feature/eks-infrastructure` branch and its pull request for the complete example.
